___


## 3.3.a **Default route**

Trasa "ostatniej szansy" (Gateway of last resort). Router używa jej tylko wtedy, gdy docelowy adres IP pakietu nie pasuje do żadnej innej, bardziej szczegółowej sieci w tabeli routingu. Używana zazywczaj na routerach brzegowych do kierowania całego nieznanego ruchu w stronę Internetu (ISP). 
- *IPv4*: Zapisywana jako cel `0.0.0.0` z maską `0.0.0.0`.
- *IPv6*: Zapisywana jako cel `::/0`.
#### Komendy:
```
router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1
router(config)# ipv6 route ::/0 2001:db8:feed::1
```
___


## 3.3.b **Network route**

Standardowa trasa statyczna kierująca ruch do konkretnej podsieci. Stosowana, gdy chcemy wskazać routerowi drogę do odległego oddziału lub sieci z innym routerem.
- *IPv4*: Wymaga podania adresu podsieci oraz jej pełnej maski dziesiętnej (np. `192.168.10.0 255.255.255.0)`.
- *IPv6*: Wymaga podania prefiksu sieci i długości maski (np. `2001:db8:acad:1::/64`).
#### Komendy:
```
router(config)# ip route 192.168.10.0 255.255.255.0 10.0.0.2
router(config)# ipv6 route 2001:db8:acad:1::/64 2001:db8:1::2
```
___


## 3.3.c **Host route**

Ultra-precyzyjna trasa prowadząca do jednego, konkretnego adresu IP (najczęściej bardzo ważnego serwera). Zgodnie z zasadą Longest prefix match, jeśli router ma w tabeli trasę do całej sieci oraz trasę Host route do jednego serwera w tej sieci, pakiet do tego serwera zawsze poleci trasą dla hosta.
- *IPv4*: Używa maksymalnej maski `/32` zapisywanej jako `255.255.255.255`.
- *IPv6*: Używa maksymalnej maski `/128`.
#### Komendy:
```
router(config)# ip route 192.168.100.5 255.255.255.255 10.0.0.3
router(config)# ipv6 2001:db8:cafe::99/128 2001:db8:1::3
```
___


## 3.3.d **Floating static**

Jest to zapasowa (awaryjna) trasa statyczna, która w normalnych warunkach jes ukryta i nie figuruje w tabeli routingu. Tworzy się ją poprzez sztuczne zwiększenie jej Dystansu Administracyjnego (AD) tak, aby był on wyższy niż AD trasy głównej. Dopiero gdy główne połączenie ulegnie awarii (trasa główna znika z tabeli), router "wynurza" (ang. floats) tę trasę i zaczyna z niej korzystać.
#### Komendy:
```
router(config)# ip route 0.0.0.0 0.0.0.0 10.10.10.2 130
router(config)# ipv6 route ::/0 2001:db8:abcd::2 150
```
