## 2.1.a **Access ports (data and voice)**
Port dostępowy (Access port) służy do podłączenia urządzeń końcowych i domyślnie przenosi ruch tylko dla jednego, przypisanego mu VLAN-u (tzw. Data VLAN), z którego zdejmuje wszelkie tagi 802.1Q, wysyłając do komputera zwykłe ramki. Wyjątkiem są środowiska z telefonami IP Cisco. Ponieważ telefony te posiadają wbudowany mini-switch (komputer podłączamy do telefonu, a telefon jednym kablem do przełącznika), na jednym porcie fizycznym konfigurujemy tzw. Voice VLAN. W efekcie port ten przepuszcza zwykły, nietagowany ruch z komputera (Data VLAN) oraz dodatkowo odbiera otagowany protokołem 802.1Q ruch z telefonu (Voice VLAN). Pozwala to na pełną separację oraz priorytezację (QoS) krytycznego dla opóźnień ruchu głosowego.
#### Komendy:
```
switch(config)# interface f0/1
switch(config-if)# switchport mode access
switch(config-if)# switchport access vlan 10
switch(config-if)# switchport voice vlan 20
switch# show interfaces f0/1 switchport
```

## 2.1.b **Default VLAN**
Na każdym przełączniku Cisco domyślnym VLAN-em "prosto z pudełka" jest zawsze VLAN 1. Fabrycznie wszystkie porty są do niego przypisane, a samego VLAN-u 1 nie można zawiesić, usunąć, ani zmienić jego nazwy. Oprócz ruchu użytkowników, VLAN 1 domyślnie przenosi również ruch protokołów kontrolnych (np. CDP, PAgP, VTP). Zgodnie z najlepszymi praktykami bezpieczeństwa na egzaminie CCNA, nie należy wykorzystywać VLAN-u 1 do obsługi ruchu stacji końcowych. Wszystkie aktywne porty dostępowe powinny zostać przeniesione do innych, specjalnie utworzonych VLAN-ów, a nieużywane porty powinny być wyłączone i przypisane do odizolowanego "black-hole" VLAN-u.
#### Komendy:
```
(Dobra praktyka, wyłączenie portów z VLAN 1)

switch(config)# vlan 999
switch(config-vlan)# name Blackhole
switch(config-vlan)# exit
switch(config)# int range f0/1 - 24
switch(config-if-range)# switchport mode access
switch(config-if-range)# switchport access vlan 999
switch(config-if-range)# shutdown
```

## 2.1.c **InterVLAN connectivity (VLAN routing)**
Ponieważ każdy VLAN tworzy całkowicie izolowaną sieć (osobna podsieć IP), urządzenia w różnych VLAN-ach nie mogą komunikować się między sobą w warstwie 2 (L2). Aby wymienić między nimi dane, niezbędne jest użycie urządzenia warstwy 3 (L3) wykonująceg routing. Egzamin CCNA wymaga znajomości dwóch głównych metod. 
Pierwsza to Router-on-a-Stick (ROAS), gdzie jeden fizyczny interfejs routera łączy się ze switchem za pomocą łącza trunk i jest logicznie podzielony na subinterfejsy (np. f0/0.10, f0/0.20), z których każdy obsługuje inny VLAN. 
Druga, znacznie wydajniejsza i stosowana w nowoczensych sieciach metoda, to wykorzystanie przełącznika warstwy 3 (Multilayer Switch). Uruchamia się na nim wirtualne interfejsy SVI (Switched Virtual Interfaces, np. `interface vlan 10`), a po wydaniu globalnej komendy `ip routing`, switch zaczyna sprzętowo trasować pakiety między przypisanymi do niego podsieciami.
#### Komendy:
```
(Router-on-a-stick)

router(config)# interface g0/0
router(config-if)# no shutdown
router(config-if)# exit
router(config)# interface g0/0.10
router(config-subif)# encapsulation dot1Q 10
router(config-subif)# ip address 192.168.10.1 255.255.255.0
```

```
(L3 switch / SVI)

switch(config)# ip routing
switch(config)# vlan 10
switch(config)# interface vlan 10
switch(config-if)# ip address 192.168.10.1 255.255.255.0
switch(config-if)# no shutdown
switch# show ip route
```
