Protokół NTP (Network Time Protocol, operujący na porcie UDP 123) odpowiada za precyzyjną synchronizację zegarów w sieci. Posiadanie jednolitego czasu na wszystkich urządzeniach jest absolutnie krytyczne dla rozwiązywania problemów (czytelność logów Syslog), sprwadzania ważności certyfikatów cyfrowych (np. SSL/TLS) oraz prawidłowego działania protokołów bezpieczeństwa.
___

**Hierarchia Stratum (Poziom wiarygodności)**
NTP opiera się na strukturze drzewa, w której poziom Stratum określa "odległość" danego urządzenia od źródła referencyjnego.

- *Stratum 0*: Zegary sprzętowe najwyższej precyzji (zegary atomowe, odbiorniki GPS). Nie komunikują się przez sieć.
- *Stratum 1*: Serwery NTP podłączone fizycznie kablem bezpośrednio do sprzętu Stratum 0.
- *Stratum 2 i niższe*: Urządzenia (np. routery korporacyjne), które pobierają czas przez sieć od serwerów Stratum 1. Każdy przeskok w sieci zwiększa numer Stratum o 1 (aż do Stratum 15).
- *Stratum 16*: Oznacza brak synchronizacji - czas z takiego urządzenia jest traktowany przez inne jako niewiarygodny i zostaje odrzucony.


**Dwa główne tryby działania (Client i Serwer)**
- *NTP Client*: Urządzenie pyta wskazanego serwera o podanie aktualnego czasu.
- *NTP Serwer*: Urządzenie odpowiada na zapytania klientów.

Ważna zasada: W systemie Cisco IOS, gdy router poprawnie zsynchronizuje swój czas z zewnętrznym serwerem, automatycznie i domyślnie zaczyna pełnić rolę serwera NTP dla innych urządzeń w swojej sieci LAN. Nie wymaga to włączania żadnej dodatkowej usługi. 


## **Komendy**

**Konfiguracja trybu Klienta**:
```
router(config)# ntp server 8.8.8.8
router(config)# ntp server 1.1.1.1 prefer
```

**Konfiguracja wymuszonego trybu Serwera (NTP Master)**:
Stosowana, gdy router znajduje się w sieci odciętej od internetu i nie ma jak pobrać czasu z zewnątrz. Komenda ta każe routerowi zaufać swojemu wewnętrznemu, sprzętowemu zegarowi kwarcowemu i rozgłaszać czas do reszty sieci.
```
router(config)# ntp master 3
```

**Weryfikacja**:
Najważniejsza komenda do sprawdzenia, czy synchronizacja się powiodła. Pokazuje, czy zegar jest zsynchronizowany, na jakim poziomie Stratum operuje obecnie router i jaki jest adres IP źródła referencyjnego.
```
router# show ntp status
Clocs is synchronized, stratum 2, reference is 1.1.1.1
nominal freq is 250.0000 Hz, actual freq is 250.0000 Hz, precision is 2**10
```

Pokazuje szczegółową tabelę wszystkich serwerów, z którymi nasz router próbuje rozmawiać.
```
router# show ntp associations
  address        ref clock      st   when   poll   reach   delay   offset   disp 
*~1.1.1.1        10.1.1.1        1     43     64     377   1.134    2.345  4.231 
  8.8.8.8        10.2.2.2        2     12     64     377   3.234    5.123  8.432
```
`*` serwer, który został wybrany jako główne i aktualne źródło czasu.
`~` serwer jest skonfigurowany na sztywno, a nie wykryty dynamicznie
