___


**Etherchannel**: Pozwala na logiczne zgrupowanie kilku fizycznych kabli (od 2 do 8 aktywnych) łączących dwa urządzenia, tworząc z nich jeden wirtualny interfejs (tzw. Port-Channel). Rozwiązuje to problem protokołu Spanning Tree (STP), który w normalnych warunkach zablokowałby nadmiarowe linki, by zapobiec pętlom. Dzięki EtherChannel otrzymujemy zwielokrotnioną przepustowość (load balancing) oraz redundancję (awaria jednego kabla nie przerywa działania całości), a STP traktuje to połączenie jako pojedynczy, bardzo szybki kabel.
___


**LACP (Link Aggregation Control Protocol)**: Egzamin CCNA wymaga znajomości otwartego standardu LACP (IEEE 802.3ad) - jest on preferowany, ponieważ w przeciwieństwie do PAgP (własność Cisco) pozwala połączyć urządzenia różnych producentów. LACP dynamicznie negocjuje powstanie kanału przy użyciu dwóch trybów:
- *Active*: Port jest agresywny - aktywnie wysyła pakiety LACP i próbuje nawiązać połączenie.
- *Passive*: Port jest pasywny - nasłuchuje pakietów LACP, ale sam ich pierwszy nie wyśle. Aby EtherChannel wstał, przynajmniej jedna strona musi być w trybie Active (połączenia Active-Active lub Active-Passive).
___


**Ważne**: Wszystkie fizyczne porty wchodzące w skład grupy muszą być identyczne. Muszą mieć tą samą szybkość, duplex, a w przypadku portów L2 - ten sam tryb (access/trunk), ten sam Native VLAN i te same dozwolone VLAN-y.
___


**Layer 2 vs Layer 3 EtherChannel**:

- *Layer 2*: Porty działają w warstwie drugiej, agregujemy zwykłe porty przełącznika (najczęściej jako łącza Trunk między dwoma switchami). Konfigurację VLAN/Trunk wykonuje się na logicznym interfejsie Port-Channel.
#### Komendy:
```
switch(config)# int range f0/1-2
switch(config-if-range)# channel-group 1 mode active
switch(config-if-range)# exit

swtich(config)# int port-channel 1
switch(config-if)# switchport trunk encapstulation dot1q
switch(config-if)# switchport mode trunk
switch(config-if)# switchport trunk allowed vlan 10,20
```



- *Layer 3*: Porty działają w warstwie sieciowej, zachowując się jak interfejsy routera. Wymaga to przełącznika warstwy 3 (L3). Na portach fizycznych należy najpierw wyłączyć tryb L2 komendą `no switchport`, a sam wirtualny interfejs Port-Channel otrzymuje adres IP. Rozwiązanie to jest używane w nowoczesnych sieciach szkieletowych, ponieważ eliminuje potrzebę działania protokołu STP mięzy tymi urządzeniami.
#### Komendy:
```
switchl3(config)# ip routing
switchl3(config)# int range f0/1-3
switchl3(confgig-if-range)# no switchport
switchl3(config-if-range)# channel-group 1 mode active
switchl3(config-if-range)# exit

switchl3(config)# int port-channel 1
switchl3(config-if)# ip address 10.0.0.1 255.255.255.252
```
