___

Te protokoły są absolutnie kluczowym narzędziem dla administratorów do mapowania topologii sieci i rozwiązywania problemów. Działają one wyłącznie w warstwie 2 (Data Link), co oznacza, że urządzenia nie muszą mieć skonfigurowanych adresów IP, aby się nawzajem "widzieć". Przekazują one informacje m.in. o nazwie (hostname), fizycznym modelu sprzętu, portach użytych do połączenia oraz możliwościach urządzenia (np. czy sąsiad to switch, router, czy telefon). Protokoły te widzą tylko bezpośrednio podłączonych sąsiadów.


___
**CDP (Cisco Discovery Protocol)**: To zamknięty, własnościowy protokół firmy Cisco. Na urządzeniach tej firmy jes on włączony domyślnie (zarówno globalnie, jak i na wszystkich interfejsach). CDP wysyła komunikaty (tzw. advertisements) standardowo co 60 sekund, a jego czas wygasania (hold-time) wynosi 180 sekund (jeśli co 3 minuty nie nadejdzie nowy komunikat od sąsiada, zostanie on usunięty z tabeli). Ze względów bezpieczeństwa najlepszą praktyką na egzaminie CCNA jes wyłączanie CDP na portach, które prowadzą do niezaufanych sieci (np. w stronę internetu) lub bezpośrednio do komputerów użytkowników, aby nie zdradzać szczegółów infrastruktury.
#### Komendy:
```
router(config)# cdp run
router(config)# no cdp run

router(config)# int f0/1
router(config-if)# no cdp enable
router(config-if)# cdp enable

router# show cdp neighbors
router# show cdp neighbors detail
router# show cdp entry *
router# show cdp interface
```
___


**LLDP (Link Layer Discovery Protocol)**: To otwarty standard branżowy (IEEE 802.1AB). Jego główną przewagą nad CDP jest to, że jest neutralny względem producentów (vendor-neutral) - pozwala urządzeniom Cisco "dogadać się" i wykryć urządzenia innych firm (np. przełączniki HP, routery Juniper czy telefony innych marek).
W przeciwieństwie do CDP, LLDP na urządzeniach Cisco jest domyślnie wyłączony i należy go włączyć ręcznie. Domyślne czasy dla LLDP to wysyłanie komunikatów co 30 sekund i czas wygasania 120 sekund. W LLDP konfiguracja interfejsu pozwala na granulację - możemy niezależnie włączyć samo wysyłanie (transmit) lub samo odbieranie (receive) komunikatów.
#### Komendy:
```
router(config)# lldp run
router(config)# no lldp run

router(config)# int f0/1
router(config-if)# lldp transmit
router(config-if)# lldp receive

router# show lldp neighbors
router# show lldp neighbors detail
```
