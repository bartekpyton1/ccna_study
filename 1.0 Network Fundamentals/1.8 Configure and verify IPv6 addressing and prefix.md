

## Konfiguracja w Cisco

**Przypisanie adresu IPv6 i maski do interfejsu:**
```
router(config)# ipv6 unicast-routing
router(config)# int f0/1
router(config-if)# ipv6 address [adres_ipv6]/[dlugosc_prefixu]
router(config-if)# no shut
```

**Sprawdzenie konfiguracji adresów IPv6**:
```
router# show ipv6 interface brief
```
