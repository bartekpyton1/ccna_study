
## 1. Rodzaje adresów IPv6
#### 1.1. Adres global
***Zakres od 2000 do 3FFF (2000::/3)***
Umożliwia globalną komunikację między hostami. Indywidualny adres publiczny widoczny w sieci internet, typu unicast.
```
2001:0db8:85a3:0000:0000:8a2e:0370:7334 
```
___
#### 1.2. Adres multicast
***Zakres od FF00::/8***
Umożliwia wysyłanie komunikatów do określonych urządzeń znajdujących się w tej samej grupie.
```
FF00:0000:0000:0000:0000:0000:0000:0001
```
___
#### 1.3. Adres link-local
***Zakres od FE80::/10***
Służy on do komunikacji urządzeń w obrębie jednej domeny rozgłoszeniowej. Adres może zostać nadany przez administratora bądź automatycznie.
```
fe80:0000:0000:0000:1416:7b24:909e:a333 
```
___
#### 1.4. Adres loopback
***::1/128***
Służy on do sprawdzania lokalnego urządzenia, wysyłając komunikaty do samego siebie.
```
0000:0000:0000:0000:0000:0000:0000:0001 
```
___
#### 1.5. Adres unspecified (nieokreślony)
***::/128***
Służy urządzeniom nie posiadającym adresu IPv6 do komunikacji np z serwerem DHCP w celu uzyskania adresu.
```
0000:0000:0000:0000:0000:0000:0000:0000
```
___

## 2. Neighbour Solicitation i Neighbour Advertisment (ARP w IPv6) 

**Arp w IPv6**
Zastąpiło ARP w sieciach IPv6. Zamiast wysyłać broadcast w całej domenie rozgłoszeniowej, wysyłany jest multicast do grupy do której należy docelowe urządzenie w tej domenie rozgłoszeniowej. 
Każde urządzenie trafia do specjalnych grup tworzonych na podstawie swoich adresów IPv6. 

*Grupy te są tworzone według reguły:*
```
FF02:0000:0000:0000:0000:0001:FFxx:xxxx
```
Gdzie w miejsce x wstawia się 6 ostatnich znaków adresu IPv6 urządzenia docelowego.

*Przykładowo urządzenie posiadające adres globalny:*
```
2001:0DB8:ABCD:0001:0000:0000:0011:1116
```

*Będzie należeć do grupy:*
```
FF02:0000:0000:0000:0000:0001:FF11:1116
```

Dodatkowo ze względu, że nie znamy adresu MAC, pakiet będzie wysłany na “tymczasowy” grupowy adres MAC. Zaczyna się on od `33:33:FF` a kończy na `xx:xx:xx`, gdzie w miejsce x również wstawianych jest 6 ostatnich znaków adresu IPv6 docelowego urządzenia:
```
33:33:FF:11:11:16
```

Do grupy `FF02::1:FF11:1116` na adres MAC `33:33:FF:11:11:16` zostanie wysłany pakiet ICMP Neighbour Solicitation. W odpowiedzi dostaniemy pakiet zwrotny zwany Neighbour Advertisement od urządzenia należącego do tej grupy. W pakiecie zawarty jest faktyczny adres MAC urządzenia.
