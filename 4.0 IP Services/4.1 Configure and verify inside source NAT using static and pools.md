___

**Pojęcia**:
- *Inside local* (Wewnętrzny lokalny): Prywatny adres IP urządzenia w sieci LAN przed translacją (np. 10.10.10.1).
- *Inside global* (Wewnętrzny globalny): Publiczny adres IP (od operatora ISP), pod którym prywatny komputer jest widoczny dla internetu po przejściu przez router.
- *Outside Local / Outsisde Global*: Adresy serwerów docelowych w internecie (z perspektywy CCNA zazywczaj są tożsame).
___
## **Static NAT**

Mapowanie "jeden do jednego" (1:1). Jeden prywatny adres IP jest "na sztywno" połączony z jednym publicznym adresem IP. Stosuje się go wyłącznie dla lokalnych usług (np. serwer WWW lub poczty), które muszą być zawsze, niezmiennie i inicjatywnie osiągalne z zewnątrz.
___

## **Dynamic NAT with Pools**

Mapowanie "wiele do wielu". Posiadasz wykupioną pulę publicznych adresów IP (np. 10 adresów) i przypisujesz je dynamicznie do komputerów z sieci LAN. Słabość tej metody polega na tym, że jeśli w firmie jest 50 komputerów, a tylko 10 adresów w puli, to 11-ty pracownik nie uzyska dostępu do internetu, dopóki któś inny nie zakończy sesji. Do konfiguracji potrzebujesz weryfikatora (lista ACL mówiąca kogo tłumaczyć) oraz puli docelowej.
___

## **PAT (Port Address Translation) / NAT Overload**

Najpowszechniejsza forma w nowoczesnych sieciach. Mapowanie "wiele do jednego". Rozwiązuje problem braku adresów w puli, ponieważ router używa dodatkowo numerów portów warstwy 4 (TCP/UDP) do identyfikacji poszczególnych komputerów. Dzięki tem tysiące maszyn w sieci LAN może jednocześnie korzystć z internetu pod tym samym, jednym publicznym adresem IP. Konfiguracja polega po prostu na dodaniu na końcu słowa `overload.`
___

## **Komendy**

**Wstępna konfiguracja**:
```
router(config)# int g0/0
router(config-if)# ip nat inside
router(config-if)# int g0/1
router(config-if)# ip nat outside
```


**Static NAT**:
```
router(config)# ip nat inside source static 10.10.10.1 172.16.131.254
```


**Dynamic NAT with Pools**:
```
router(config)# access-list 1 permit 192.168.1.0 0.0.0.255
router(config)# ip nat pool PULA_ISP 203.0.113.10 203.0.113.20 net mask 255.255.255.0
router(config)# ip nat inside source list 1 pool PULA_ISP
```


**PAT**:
```
router(config)# ip nat inside source list 1 pool PULA_ISP overload

lub

router(config)# ip nat inside source list 1 int g0/1 overload
```
